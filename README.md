**Use [Supabase](https://supabase.com) from Ruby and Rails.** `supabase-rb` is
a single gem that wraps every Supabase product — Auth, PostgREST (Database),
Storage, Edge Functions, and Realtime — behind one `Supabase.create_client`
factory.

> **Documentation:** [supabase-ruby.dev](https://supabase-ruby.dev) ·
> **Reference:** [supabase-ruby.dev/reference](https://supabase-ruby.dev/reference) ·
> **Gem:** [rubygems.org/gems/supabase-rb](https://rubygems.org/gems/supabase-rb)

## Quickstart

Add the gem to your `Gemfile` (works in any Ruby app, including Rails):

```ruby
# Gemfile
gem "supabase-rb"
```

Then install and run a first query:

```ruby
require "supabase"

supabase = Supabase.create_client(
  supabase_url: ENV.fetch("SUPABASE_URL"),
  supabase_key: ENV.fetch("SUPABASE_ANON_KEY"),
)

response = supabase.from("countries").select("*").limit(1).execute
puts response.data
# => [{"id" => 1, "name" => "United Kingdom"}]
```

Requires Ruby ≥ 3.1. Full reference at
[supabase-ruby.dev/reference](https://supabase-ruby.dev/reference) — Auth,
Database, Realtime, Storage, and Edge Functions.

## Local Development

### Clone the Repository

```bash
git clone https://github.com/supabase-ruby/supabase-rb.git
cd supabase-rb
```

### Dependencies

This repository relies on the following dependencies for development:
- `ruby` >= 3.1 for the gem itself.
- `bundler` for installing gem dependencies.
- `docker` for the `auth` (GoTrue) test containers under `infra/`.
- `supabase-cli` for the optional Realtime live integration spec.

### Install gem dependencies

The repo ships a single `supabase-rb.gemspec` that packages every module under
`lib/supabase/`. `bundle install` is the only setup step:

```bash
bundle install
```

### Running tests and other commands

Auth integration specs need the GoTrue infrastructure on ports 9996–9999:

```bash
docker compose -f infra/docker-compose.yml up -d
```

Run the full suite:

```bash
bundle exec rspec
```

Run a single sub-library's specs:

```bash
bundle exec rspec spec/supabase/postgrest/
bundle exec rspec spec/supabase/storage/
bundle exec rspec spec/supabase/functions/
bundle exec rspec spec/supabase/realtime/
bundle exec rspec spec/supabase/client_spec.rb     # umbrella
```

Coverage is generated by SimpleCov to `coverage/index.html`.

Other relevant commands:

```bash
docker compose -f infra/docker-compose.yml down   # stop all auth containers
rm -rf coverage/                                  # delete intermediary test files
```

### Realtime live integration (`spec/integration/`)

`spec/integration/realtime_smoke_spec.rb` exercises the WebSocket transport,
join handshake, broadcast send/receive, and unsubscribe path against a real
Supabase Realtime server. It is **skipped automatically** if
`SUPABASE_INTEGRATION_URL` is not set, so the full suite stays green without
a running stack:

```bash
bundle exec rspec                                 # smoke spec marked skipped
```

To run it locally against a Supabase stack:

```bash
# 1. Start a local stack (Supabase CLI gives you Realtime + REST + Auth).
supabase start

# 2. Export the project URL and anon key shown by `supabase status`.
export SUPABASE_INTEGRATION_URL=http://127.0.0.1:54321
export SUPABASE_INTEGRATION_KEY=<anon key>

# 3. Run the smoke spec (subscribe/receive bounded at 5 s each, total < 15 s).
bundle exec rspec spec/integration/realtime_smoke_spec.rb
```
